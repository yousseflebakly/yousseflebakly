## 🚀 Featured Project

### [Nexus Graph Explorer — Angular 3D Visualization](https://github.com/youssefelbakly/angular-3d-graph-visualization)

An interactive 3D graph visualization application developed using **Angular, TypeScript, and 3d-force-graph**.

**Key Features:**

- Interactive 3D graph with 360° rotation, zoom, and clickable nodes.
- Search and filtering functionality for exploring graph data.
- Node inspection with relationship information.
- Responsive dashboard with a modern dark interface.
- Front-End prototype powered by mock data, structured for potential future backend integration.

**Technologies:** Angular, TypeScript, JavaScript, HTML, CSS, 3d-force-graph.
